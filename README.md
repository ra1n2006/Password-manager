# Менеджер паролей

Консольное приложение для безопасного хранения паролей от различных сервисов. Приложение позволяет добавлять, просматривать и удалять пароли, а также генерировать надёжные пароли.

## Возможности

- Создание мастер-пароля и проверка его корректности.
- Шифрование паролей перед сохранением.
- Добавление паролей для различных сервисов.
- Просмотр списка сохранённых сервисов.
- Получение пароля после подтверждения мастер-пароля.
- Удаление сохранённых паролей.
- Генерация случайных надёжных паролей.

## Установка

1. Клонируйте репозиторий:

   ```bash
   git clone 
   ```

2. Перейдите в директорию проекта:

   ```bash
   cd Lab1
   ```

3. Установите зависимости:

   ```bash
   uv sync
   ```

## Запуск приложения

Из корневой директории проекта выполните:

```bash
uv run python src/main.py
```

При первом запуске приложение предложит создать мастер-пароль. При последующих запусках потребуется ввести установленный мастер-пароль.

## Команды

После запуска приложение ожидает ввода команд:

| Команда | Описание |
|---|---|
| `add` | Добавить новый пароль |
| `list` | Вывести список сохранённых сервисов |
| `get <name>` | Получить пароль для указанного сервиса |
| `delete <name>` | Удалить пароль для указанного сервиса |
| `exit` | Завершить работу приложения |

При добавлении пароля можно выбрать ручной ввод или генерацию случайного пароля.

### Назначение основных модулей

- `main.py` — точка входа в приложение.
- `cli.py` — обработка пользовательских команд.
- `manager.py` — основная логика управления паролями.
- `crypto.py` — генерация ключей, хеширование и шифрование.
- `generator.py` — генерация случайных паролей.
- `storage.py` — чтение и запись данных в JSON-файл.
- `tests/` — автоматические тесты проекта.

## Запуск тестов

Для запуска всех тестов выполните:

```bash
uv run pytest -v
```

## Безопасность

- Мастер-пароль хранится в виде хеша, а не в открытом виде.
- Сохранённые пароли шифруются перед записью в файл.
- Ключ шифрования хранится в файле `.env`.
- Файлы с пользовательскими данными и секретами не следует добавлять в публичный репозиторий.

**Важно:** при потере ключа шифрования восстановить зашифрованные пароли будет невозможно.
